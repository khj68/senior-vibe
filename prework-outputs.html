프론트엔드 기초

바이럴 MVP, 어드민, 측정 리포트 화면 모두 프론트엔드가 필요합니다. 처음에는 화려한 UI보다 화면 구조, 상태, API 연결을 이해하는 것이 중요합니다.

1단계

HTML/CSS/JavaScript

  • semantic HTML, form, button, input, video element
  • flex/grid, responsive layout, mobile viewport
  • DOM event, click handler, conditional rendering 기초

2단계

React 기초

  • component, props, state, effect 개념
  • 설문 진행 상태, 결과 타입, 카메라 허용 상태를 state로 관리
  • API 호출 결과를 화면에 반영하는 흐름

3단계

카메라/미디어 기초

  • 브라우저 카메라 권한과 video preview 흐름
  • 권한 거부, 기기 없음, 모바일 브라우저 이슈
  • 카메라 기능은 선택형으로 두는 UX 설계

측정 리포트 측정값 표시, 그래프/표, 사용자 친화 문구, PDF/프린트 화면 박하준, 손민준
어드민 목록, 필터, 검색, 상세 페이지, 권한별 화면 박하준, 이수빈

서버/API/AWS 기초

서버는 화면 뒤에서 데이터 저장, 결과 계산, AI 호출, 로그인, 로그 기록을 담당합니다. AWS는 이 서버와 데이터가 실제로 배포되는 환경으로 이해하면 됩니다.

서버 기초

Node.js/API

  • request, response, route, middleware 개념
  • REST API와 JSON 응답 구조
  • 입력값 검증과 에러 응답의 기본

데이터 기초

DB/Storage

  • 사용자, 설문 답변, 측정 결과, 리포트 테이블 구조
  • SQL과 NoSQL의 차이 정도만 먼저 이해
  • 영상/이미지 파일은 DB가 아니라 storage에 두는 흐름

클라우드 기초

AWS

  • EC2, S3, RDS, Lambda가 무엇을 담당하는지 개념 이해
  • 환경변수, IAM 권한, CloudWatch 로그의 필요성
  • 개발/운영 환경을 분리해야 하는 이유
주제 기초 질문 시니어바이브에서 쓰이는 곳
API 프론트에서 보낸 설문 답변을 서버가 어떻게 받는가? 어깨 나이 결과 계산, 리포트 저장, 어드민 조회
DB 측정 기록과 사용자 정보를 어떤 구조로 저장하는가? 키오스크 측정 이력, 일본 멤버십 앱, 어드민
S3/Storage 이미지나 리포트 파일은 어디에 저장하는가? 측정 캡처, 결과 리포트, 공유 이미지
로그/모니터링 사용자가 실패했을 때 원인을 어떻게 찾는가? 카메라 권한 실패, 측정 실패, API 오류 분석

LLM/ML/CV 기초

LLM과 ML은 같은 AI라고 묶이지만 쓰임새가 다릅니다. 시니어바이브에서는 LLM은 설명과 문구 생성, ML/CV는 카메라 측정과 각도 추정에 가깝습니다.

LLM 기초

문구 생성/요약/분류

  • prompt, system message, user message, structured output 개념
  • 결과 문구 생성, FAQ 답변, 상담 전 요약에 활용
  • 의료 과장 표현과 hallucination을 막는 검수 기준 필요

ML 기초

모델 학습과 평가

  • dataset, label, train/validation/test 개념
  • 사전학습 모델, fine-tuning, overfitting의 의미
  • 정확도보다 실패 케이스를 기록하는 습관

CV 기초

Pose/ROM 측정

  • keypoint, bounding box, confidence score 개념
  • 어깨, 팔꿈치, 손목 좌표로 각도를 계산하는 기본 기하
  • 카메라 거리, 조명, 옷, 자세가 결과에 미치는 영향

LLM이 들어갈 수 있는 곳

어깨 나이 테스트 결과 설명, 리포트의 쉬운 문장 변환, 사용자 FAQ, 상담 전 요약, 관리자용 이슈 분류에 활용할 수 있습니다. 단, 의료 조언처럼 보이는 문장은 반드시 제한해야 합니다.

ML/CV가 들어갈 수 있는 곳

키오스크와 카메라 기반 ROM 측정에서 관절 keypoint 추출, 각도 계산, 실패 케이스 분류에 활용됩니다. 바이럴 MVP에서는 정밀 측정보다 기술 체험 수준으로만 쓰는 것이 안전합니다.

팀별 추천 학습 묶음

모든 기술을 다 공부시키기보다, 각 팀에 필요한 최소 묶음부터 시작합니다.

R&D/ROM 팀: 이형진 + 박하준

  • 필수: CV 기초, pose estimation, ROM 각도 계산, 실험 로그 작성
  • 보조: Python 데이터 처리, 간단한 API 이해, AWS S3/로그 개념
  • 서비스 연결: 키오스크 측정, 카메라 기반 ROM, R&D 지원금 실험 기록

바이럴 MVP 팀: 손민준 + 이여진 + 이수빈

  • 필수: HTML/CSS/JS, React 상태 관리, API 호출, 설문 UX
  • 보조: LLM API 기초, 브라우저 카메라, AWS 배포/로그 개념
  • 서비스 연결: 어깨 나이 테스트, 공유 결과 페이지, 상담/측정 전환 CTA
